# Standard-library modules no compile-time parity case reaches, with the reason ("<module> <reason>"). The list only
# shrinks (tools/test-compile-time-parity-guard.sh): a new module comes with a case that reaches it, and a line goes
# once a case does. "(5)" marks the modules item (5) of the parity plan gives a case (ablac-9e's survey, 2026-11-15).
#
# Build-time and target-specific: they produce or run another target's program, which `#` in this compiler doesn't.
abla/android/build builds an Android target (apk, aar); the program is a build script, not run at run time
abla/android/emutls Android's emulated thread-local storage, linked into an Android target only
abla/ios/build builds an iOS target
abla/wasm/build builds a WebAssembly target
abla/mvc/wasm/build builds abla/mvc's WebAssembly client
abla/unsafe/xtensa Xtensa registers and interrupts: an ESP32 target only
abla/xtensa/companion an ESP32's host companion over a serial link: needs the device
abla/xtensa/companion/httpstream an ESP32's host companion over a serial link: needs the device
abla/xtensa/companion/native an ESP32's host companion over a serial link: needs the device
# The compiler's and the tools' own.
abla/compiler/bridge the native side of the compiler bridge: generated stubs replace its externs under `#`, nothing to compare
abla/live redefines a running program's functions under `ablac run --live`; `#` has no running program
abla/test checks for `ablac test` programs (prints FAIL lines): a case would compare the checks, not the module
abla/runtime/erased-float the runtime's erased-float helpers, linked when a target needs them (not x86-64 or AArch64 Linux)
# Host-dependent.
abla/device character devices: a device the case opens is the host's, under `#` the compiler's
abla/serial serial-port configuration over abla/device
