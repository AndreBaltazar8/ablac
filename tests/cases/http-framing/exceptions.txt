# Streams on which Abla frames a request llhttp refuses (compare.mjs): "name reason". Abla refusing more than llhttp is not listed.
lower-method methods are any token (RFC 9110 9.1); llhttp only knows registered ones
unknown-method methods are any token; llhttp only knows registered ones
long-method methods are any token; llhttp only knows registered ones
method-digit methods are any token (digits are token characters)
target-del the request target is passed on as received (DEL)
target-8bit the request target is passed on as received (UTF-8 in a URL)
cl-dup-same identical duplicate Content-Length values may be combined (RFC 9110 8.6)
te-tab tab is optional whitespace around a field value (RFC 9110 5.5)
ch-ext-space-after whitespace after the semicolon of a chunk extension is allowed (RFC 9112 7.1.1)
ch-ext-tab-after whitespace after the semicolon of a chunk extension is allowed (RFC 9112 7.1.1)
