# builds each of them --fast for x86_64-windows-hosted, compares the run under Wine with the Linux run, and leaves the images for the
# Windows runner: tools/windows/test-hosted.ps1, the windows-run job in ci.yml).
#
# <path of the program> <its exit status> [runner]
#
# `runner`: Wine cannot check it (Wine's CreateSymbolicLinkW reports success and makes no link), so the Wine run is skipped and
# only the Windows runner runs it.
# `wine`: the opposite: the program passes under Wine and is not left for the Windows runner, where it fails (none now;
# tools/windows/debug-programs.ps1 prints what happens to a --backtrace build of one on the runner).
