# The libSystem imports the macOS compiler and test programs may have (#811, see tools/test-libsystem-imports.sh).
# Lines starting with # are documentation; every other line is "<subject> <symbol>".
# A line ending in " ?" is expected to go but was not checked on a Mac before it landed: allowed while imported,
# reported once it is not (then remove it). tools/macos-local-imports.sh checks the program lines on Linux.
#
# The compiler no longer imports _malloc, _free, _realloc, _pthread_mutex_lock, _pthread_mutex_unlock, _pthread_key_create,
# _pthread_getspecific or _pthread_setspecific (#826): they were compiler-rt's emulated TLS. ORC lowers the thread-locals of a
# JIT'd program (`ablac run`) to emulated TLS (LLJIT has no MachOPlatform, so no native TLV), and the compiler's
# ___emutls_get_address is now abla/runtime/emutls (src/emutls_export.ab), on the Abla heap and atomics; src/toolchain.ab:4469-4471
# still links with -Wl,-u,___emutls_get_address so that it is in the exported host image. User programs use native TLV
# (__tlv_bootstrap) and had none of these. Not checked on a Mac before CI: that nothing else in the compiler (libLLVM linked
# statically, OpenSSL) imports them; a line that returns is that import's, not emutls's.
