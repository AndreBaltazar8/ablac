# The compiler no longer imports _malloc, _free, _realloc, _pthread_mutex_lock, _pthread_mutex_unlock or _pthread_getspecific
# (#826): they were compiler-rt's emulated TLS. It imports _pthread_key_create and _pthread_setspecific again for one purpose:
# a thread the runtime did not start (a host's pthread calling the compiler's JIT path, a thread of LLVM's) is freed of its
# emulated thread-locals by a key's destructor (abla/runtime/emutls); not checked on a Mac before CI. ORC lowers the thread-locals of a
# JIT'd program (`ablac run`) to emulated TLS (LLJIT has no MachOPlatform, so no native TLV), and the compiler's
# ___emutls_get_address is now abla/runtime/emutls (src/emutls_export.ab), on the Abla heap and atomics; src/toolchain.ab:4469-4471
# still links with -Wl,-u,___emutls_get_address so that it is in the exported host image. User programs use native TLV
# (__tlv_bootstrap) and had none of these. Not checked on a Mac before CI: that nothing else in the compiler (libLLVM linked
# statically, OpenSSL) imports them; a line that returns is that import's, not emutls's.
