# Lines starting with # are documentation; every other line is "<subject> <symbol>".

# The compiler's _malloc, _free, _realloc, _pthread_mutex_lock, _pthread_mutex_unlock (and its _pthread_key_create,
# _pthread_getspecific, _pthread_setspecific) are compiler-rt's emulated TLS, not the compiler's own code: ORC lowers
# the thread-locals of a JIT'd program (`ablac run`) to emulated TLS (LLJIT has no MachOPlatform, so no native TLV),
# and src/toolchain.ab:4469-4471 links every LLVM-linking macOS build with -Wl,-u,___emutls_get_address so that
# ___emutls_get_address is in the exported host image (b3fbf152). User programs use native TLV (__tlv_bootstrap) and
# have none of these. A native-TLV JIT (a MachOPlatform for LLJIT) or an emutls of our own would remove them (todo, #815).
