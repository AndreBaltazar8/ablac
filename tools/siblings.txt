# The sibling repositories tools/test-siblings.sh checks (the release's downstream step), one a line:
#   <repository directory beside ablac> <TAB> <test command, run in it>   ("-" for programs only)  [<TAB> postgres=<database>]
# A third column `postgres=<database>` starts a throwaway PostgreSQL for that repository's tests (nix's, a temporary data directory, a free port on 127.0.0.1,
# trust authentication, stopped after) and gives them POSTGRES_HOST, POSTGRES_PORT, POSTGRES_DB and POSTGRES_USER; no system service is touched.

# repository's CI runs, else its `make test`. Keep one line per repository; add new siblings here.
